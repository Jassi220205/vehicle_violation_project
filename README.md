This project implements an end-to-end **Overspeed Vehicle Detection System** that analyzes traffic videos to detect vehicles and identify overspeeding instances. It leverages YOLOv8 for real-time vehicle detection, combined with frame-based motion analysis to estimate speed. A lightweight web interface built using Flask allows users to upload videos and view processed outputs with highlighted violations. The system demonstrates the integration of computer vision, deep learning, and web deployment in a practical traffic monitoring application.
